重装后先恢复Docker和可访问的MI210驱动（`amd-smi`正常、有`/dev/kfd`及render节点），
再运行：

```bash

cd /root/int8-vllm
export MI210_API_KEY='新的API密钥'

```

恢复脚本校验文件、`docker load`镜像、恢复模型/缓存和源码，再用已验证命令
重建服务容器。恢复后的容器ID可以不同，功能由镜像、启动配置和挂载共同恢复。

`docker save`保存镜像及层，可用`docker load`恢复：
https://docs.docker.com/reference/cli/docker/image/save/
`docker export`仅保存容器文件系统，不含挂载卷：
https://docs.docker.com/reference/cli/docker/container/export/
因此不能只保存镜像或rootfs而漏掉本机模型和编译缓存。
已选源容器父镜像层数较低，提交后120层；历史9b44镜像127层，勿再叠加多层。
